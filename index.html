🔧 Principais Comandos do Git

Configuração Inicial

Configure seu nome e email no Git:

git config --global user.name "Seu Nome" git config --global user.email "seu@email.com"

Criar Repositório

Inicia um novo repositório Git:

git init

Clonar Repositório

Clona um repositório remoto:

git clone <url>

Adicionar Arquivos

Adiciona arquivos para staging:

git add <arquivo> git add .

Verificar Status

Mostra o status dos arquivos:

git status

Fazer Commit

Registra as alterações no repositório:

git commit -m "Mensagem do commit"

Ver Histórico

Exibe o histórico de commits:

git log git log --oneline

Criar Branch

Cria uma nova branch:

git branch <nome-branch>

Mudar de Branch

Troca para outra branch:

git checkout <nome-branch> git switch <nome-branch>

Listar Branches

Lista todas as branches:

git branch -a

Merge de Branches

Mescla uma branch na atual:

git merge <nome-branch>

Push para Remoto

Envia commits para repositório remoto:

git push origin <branch>

Pull do Remoto

Baixa e mescla alterações remotas:

git pull origin <branch>

Fetch do Remoto

Baixa alterações sem mesclar:

git fetch origin

Desfazer Alterações

Remove arquivos do staging:

git reset <arquivo> git restore <arquivo>

Deletar Branch

Remove uma branch local ou remota:

git branch -d <nome-branch> git push origin --delete <nome-branch>
